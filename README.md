FinanceOS
FinanceOS — настольное приложение для личного учёта финансов на Java. Оно хранит операции локально в SQLite и позволяет вести доходы и расходы без подключения к интернету.
Я разрабатываю FinanceOS как учебный pet-проект и инструмент для собственного использования. Основная цель — разобраться в Java, SQL, проектировании приложения и создании графического интерфейса на практике.
Статус: в разработке. Реализован базовый учёт операций с интерфейсом JavaFX.

Что уже работает
- Добавление доходов и расходов через общую форму.
- Проверка ввода: сумма должна быть положительным числом, категория обязательна, описание можно оставить пустым.
- Сохранение операций в SQLite и загрузка при следующем запуске.
- Расчёт общего баланса: доходы минус расходы.
- Таблица операций с датой и временем, типом, категорией, суммой и описанием.
- Обновление таблицы и баланса после добавления или удаления операции.
- Удаление выбранной операции с подтверждением.
- Сообщения об ошибках сохранения и удаления в графическом интерфейсе.
- Фильтр по типу: все операции, доходы или расходы.
- Сортировка таблицы, включая числовую сортировку сумм и хронологическую сортировку дат.
Фильтр меняет только видимые строки таблицы. Общий баланс продолжает учитывать все операции. Новые записи сразу учитываются текущим фильтром.
В проекте также сохранён консольный интерфейс: добавление и удаление операций, просмотр списка, поиск по ID, баланс и статистика расходов по категориям. Диаграммы и отдельный экран аналитики в JavaFX пока не реализованы.

Денежные суммы представлены типом BigDecimal. В SQLite они сохраняются в текстовом виде, чтобы не переводить их в числа с плавающей точкой.
Структура приложения
Основной код находится в src/main/java.
Класс	Ответственность
FinanceOSApp	Главное окно, таблица, фильтр и обработчики действий
TransactionDialog	Форма добавления операции и проверка ввода
TransactionFormData	Передача введённых данных из формы
Transaction	Операция: ID, сумма, категория, описание, тип и дата создания
TransactionType	Типы операций: INCOME и EXPENSE
TransactionService	Координация работы репозитория и менеджера
TransactionManager	Операции в памяти, расчёт баланса, поиск и статистика
TransactionRepository	SQL-запросы для сохранения, загрузки и удаления
DatabaseManager	Подключение к SQLite и создание таблицы
Main	Консольный интерфейс


При добавлении форма передаёт данные сервису. Репозиторий сохраняет операцию и возвращает ID из базы. Сервис добавляет сохранённую операцию в менеджер, после чего интерфейс обновляет таблицу и баланс.
Для таблицы используется ObservableList. FilteredList отбирает видимые операции, а SortedList применяет сортировку выбранного столбца. Добавление и удаление выполняются через исходный список таблицы.
Запуск
Потребуются JDK 26 и Maven. Для первоначальной загрузки зависимостей нужен интернет; сам финансовый учёт работает локально.
git clone https://github.com/m1ws38/FinanceOS.git
cd FinanceOS
mvn clean javafx:run
Либо откройте pom.xml в IntelliJ IDEA как Maven-проект, выберите JDK 26, загрузите зависимости и запустите Maven-цель javafx:run.
Графическая точка входа — FinanceOSApp. Для консольного интерфейса можно запустить класс Main из IDE.
Готового установщика пока нет.
Хранение данных
База financeos.db создаётся в рабочей директории приложения. При первом запуске автоматически создаётся таблица transactions.
Для каждой операции сохраняются:
- ID, назначенный базой данных;
- сумма;
- категория;
- необязательное описание;
- тип операции;
- дата и время создания.
Путь к базе относительный: запуск из другой рабочей директории может создать отдельный файл базы. Для ручной резервной копии закройте приложение и скопируйте financeos.db.
Текущие ограничения
- Редактирование существующих операций пока не реализовано.
- Категории вводятся свободным текстом; справочника категорий нет.
- Дата присваивается при создании операции; выбрать дату вручную пока нельзя.
- Фильтрация доступна только по типу операции.
- Нет отдельных счетов, выбора валюты и конвертации; интерфейс отображает суммы в рублях.
- Автоматизированные тесты пока не настроены. DatabaseTest и RepositoryTest — ручные проверки через main, использующие ту же базу, что и приложение.
