## FinanceOS — персональное приложение для учёта и анализа финансов, которое я разрабатываю на Java.

# Главная идея проекта — создать удобный инструмент для управления собственными деньгами и одновременно получить практический опыт разработки полноценного приложения: от бизнес-логики и работы с базой данных до графического интерфейса.

> **Статус:** 🚧 В разработке (ранний этап)

##🎯 Цели проекта

	●	Создать приложение для личного финансового учёта.
	●	Хранить данные локально, без обязательного подключения к интернету.
	●	Научиться проектировать структуру приложения и базу данных.
	●	Закрепить знания Java и SQL на реальном проекте.
	●	Постепенно разработать удобный графический интерфейс.

FinanceOS — прежде всего учебный pet-проект, а не коммерческий продукт. При этом я хочу сделать его достаточно полезным, чтобы пользоваться им самому.

#🚀 Запуск проекта

Проект пока находится на раннем этапе, поэтому готового установщика нет.

Для разработки понадобятся:

	1.	JDK, совместимый с текущей версией проекта (сейчас используется JDK 26).
	2.	IntelliJ IDEA или другая Java IDE.
	3.	SQLite JDBC Driver, подключённый к проекту.

Откройте проект в IDE, проверьте настройки JDK и наличие JDBC-драйвера в зависимостях, затем запустите основной класс приложения.

> Точные инструкции по сборке и запуску будут добавлены после стабилизации структуры проекта.

#🔒 Принципы

	●	Local-first: данные пользователя должны храниться на его устройстве.
	●	Offline-first: основные функции не должны зависеть от интернета.
	●	Постепенное развитие: сначала рабочая логика, затем интерфейс и дополнительные возможности.
	●	Обучение через практику: важнее разобраться в реализации, чем просто получить готовый код.
