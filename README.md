# FinanceOS

Настольное приложение для личного учёта финансов и расчёта накоплений. Работает локально: операции и накопительные счета хранятся в SQLite на компьютере пользователя. Это учебный pet-проект, в котором я разбираюсь с Java, JavaFX, SQL и устройством настольных приложений.

**Статус:** в разработке. Версию для Windows уже можно собирать в установщик; сборка с последними изменениями требует проверки перед распространением.

## Что работает

### Учёт операций

- Добавление доходов и расходов, редактирование и удаление операций с подтверждением.
- Хранение операций в SQLite и загрузка при следующем запуске.
- Общий баланс, таблица с сортировкой, фильтр по типу операции и включительный фильтр по диапазону дат.
- Сброс фильтров и отдельные суммы доходов и расходов за выбранный период.
- Проверка ввода в формах и сообщения о части ошибок в интерфейсе.

Фильтры меняют видимые строки и суммы **за период**. Общий баланс рассчитывается по всем операциям.

### Накопительные счета

- Добавление счёта с названием, начальной суммой и годовой ставкой.
- Сохранение счетов в SQLite, загрузка при запуске и переключение между ними.
- Прогноз на выбранное число месяцев с ежемесячным пополнением или без него, с капитализацией процентов или без неё.
- Отдельный показ вложенной суммы, начисленных процентов и итоговой суммы.

Расчёт приблизительный: проценты за месяц = текущая сумма × годовая ставка / 1200, с округлением до копеек. Пополнение учитывается в конце каждого месяца. Реальные условия банков, ежедневное начисление, изменение ставки, налоги и досрочное снятие пока не учитываются.

## Технологии

Java 26, JavaFX 26, SQLite, sqlite-jdbc 3.53.4.0 и Maven. Суммы в Java представлены через `BigDecimal`, в SQLite сохраняются как текст.

В интерфейсе доступны светлая и тёмная темы. Разметка и стили интерфейса находятся в JavaFX и CSS соответственно.

## Запуск из исходников

Нужны JDK 26 и Maven (либо Maven, встроенный в IntelliJ IDEA). При первой загрузке зависимостей потребуется интернет.

```powershell
git clone https://github.com/m1ws38/FinanceOS.git
cd FinanceOS
mvn javafx:run
```

Можно открыть `pom.xml` как Maven-проект в IntelliJ IDEA, выбрать JDK 26 и запустить цель `javafx:run`. Графическая точка входа — `FinanceOSApp`, класс `Launcher` используется для упаковки. В проекте также есть отдельный консольный интерфейс `Main`.

Для установщика Windows используются `jpackage` из JDK и WiX Toolset. Старый установщик не включает автоматически новые изменения исходников: перед передачей новой версии друзьям её нужно пересобрать и проверить.

## Где лежат данные

База создаётся по пути `%LOCALAPPDATA%\FinanceOS\financeos.db` (обычно `C:\Users\<имя>\AppData\Local\FinanceOS\financeos.db`). При запуске создаются таблицы `transactions` и `savings_accounts`. Чтобы сделать резервную копию, закройте приложение и скопируйте файл базы. На другой системе текущий путь к базе потребует адаптации.

## Основные классы

- `FinanceOSApp` — окна, таблица, фильтры и переключение между учётом операций и калькулятором.
- `TransactionService`, `TransactionManager`, `TransactionRepository` — логика операций, состояние и SQL-запросы.
- `SavingsAccount`, `SavingsCalculator`, `SavingsAccountRepository`, `SavingsAccountDialog` — данные счёта, расчёт, хранение и форма добавления.
- `DatabaseManager` — подключение к SQLite и подготовка таблиц.
